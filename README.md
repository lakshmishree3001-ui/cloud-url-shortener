# Cloud-Based URL Shortener Simulation

A complete cloud application simulation project built with Python (FastAPI), SQLite, Docker, and mapped to AWS Cloud Services.

## Project Directory Structure

```text
cloud-url-shortener/
├── app/
│   ├── __init__.py
│   ├── main.py          # FastAPI application entrypoint
│   ├── models.py        # Database models & schemas
│   ├── database.py      # SQLite connection & session
│   └── utils.py         # Base62 short code generator & URL validation
├── tests/
│   ├── __init__.py
│   └── test_api.py      # Automated API tests
├── docs/
│   ├── lab1_cloud_intro.md
│   ├── architecture_diagram.png
│   └── api_docs.md
├── Dockerfile           # Docker containerization config
├── docker-compose.yml   # Multi-container orchestration
├── requirements.txt     # Python dependencies
└── README.md            # Project overview & documentation
```
